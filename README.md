# «Распишитесь» / Please Sign Here - Цифровая подпись онлайн

Веб-приложение для создания красивой анимированной цифровой подписи. Подписывайте документы без распечатки!

## 🚀 Структура сайта

- **`/`** - Промо-страница (SEO-friendly landing page)
- **`/app`** - Приложение для создания подписи

## ✨ Особенности

- ✍️ Плавное рисование подписи (мышкой или пальцем)
- 🎬 Анимация рисования подписи
- 📤 Экспорт в PNG, GIF, SVG
- 📱 Работает на всех устройствах (PWA)
- 🔒 100% приватно - всё работает локально
- 🎨 Чистый код на Svelte 5 + TypeScript
- 🌐 SEO-оптимизированная промо-страница

## Технологии

- **Svelte 5** - реактивный UI фреймворк
- **Vite** - сборщик для быстрой разработки
- **TypeScript** - типобезопасность
- **Canvas API** - рисование
- **gifenc** - генерация GIF

## Структура проекта

```
src/
├── lib/
│   ├── components/

│   └── types/

├── App.svelte                 # Корневой компонент
├── main.ts                    # Точка входа

```

## 🎯 Решаемая проблема

**Проблема:** Вам прислали документ для подписи, но нет принтера. Подпись ручкой выглядит непрофессионально из-за зазоров и неровностей.

**Решение:** «Распишитесь» позволяет создать идеально ровную цифровую подпись с постоянным штрихом. Один раз создали - используете везде!

## 🎨 Возможности приложения

1. Выберите толщину линии на панели инструментов
2. Нарисуйте подпись на холсте
3. Используйте кнопки для:
   - **Воспроизвести** - анимация подписи
   - **PNG** - сохранить как изображение
   - **GIF** - сохранить как анимацию
   - **SVG** - сохранить как векторную графику
   - **Очистить** - удалить подпись

## Архитектура

### Управление состоянием
Используется Svelte store (`signatureStore`) для централизованного управления:
- Данные штрихов
- Ширина базовой линии
- Уведомления

### Компоненты
- **Canvas** - основной холст с обработкой touch/mouse событий
- **Toolbar** - кнопки для управления и экспорта
- **Toast** - всплывающие уведомления

### Утилиты
- **drawingEngine** - рисование кривых Безье
- **replayAnimation** - покадровое воспроизведение
- **gifExporter** - генерация GIF через gifenc
- **svgExporter** - создание SVG из штрихов
