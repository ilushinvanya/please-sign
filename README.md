# SignCanvas - Svelte

Легкий холст для подписи с возможностью воспроизведения анимации и экспортом в различные форматы.

## Особенности

- ✍️ Плавное рисование с оптимизацией точек
- 📐 Три толщины линии (тонкая, средняя, толстая)
- 🎬 Воспроизведение анимации подписи
- 📤 Экспорт в PNG, GIF, SVG
- 📱 Адаптивный дизайн
- 🎨 Чистый код на Svelte 5 + TypeScript

## Технологии

- **Svelte 5** - реактивный UI фреймворк
- **Vite** - сборщик для быстрой разработки
- **TypeScript** - типобезопасность
- **Canvas API** - рисование
- **gifenc** - генерация GIF

## Использование

1. Выберите толщину линии на панели инструментов
2. Нарисуйте подпись на холсте
3. Используйте кнопки для:
   - **Воспроизвести** - анимация подписи
   - **PNG** - сохранить как изображение
   - **GIF** - сохранить как анимацию
   - **SVG** - сохранить как векторную графику
   - **Очистить** - удалить подпись

## Архитектура

### Управление состоянием
Используется Svelte store (`signatureStore`) для централизованного управления:
- Данные штрихов
- Ширина базовой линии
- Уведомления

### Компоненты
- **Canvas** - основной холст с обработкой touch/mouse событий
- **Toolbar** - кнопки для управления и экспорта
- **Toast** - всплывающие уведомления

### Утилиты
- **drawingEngine** - рисование кривых Безье
- **replayAnimation** - покадровое воспроизведение
- **gifExporter** - генерация GIF через gifenc
- **svgExporter** - создание SVG из штрихов
